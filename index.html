Japanese Pitch Accent — Pitch Trace

Live microphone pitch trace (3-row timeline) with overlays from saved recordings or uploaded audio. The display stays black when silent; the blue line appears only when speech is detected.

Overlays: pick an example or a saved file below and click Apply.
After upload saves, it appears in the dropdown.

Usage
1) Click Start Microphone and speak a word/phrase.
2) Use Start Recording to save mic audio (shows up under “Saved Overlay”).
3) Upload an audio file to auto-transcribe and (optionally) generate an overlay.
Tip: The pitch trace wraps across 3 rows; it resets only after the last row.
Examples (Tokyo Dialect)
はし: Chopsticks (箸) vs Bridge (橋). Use the overlay buttons, then say the word and compare the contour.
あめ: Rain (雨) vs Candy (飴). Try uploading short clips and compare overlays.
はな: Flower (花) vs Nose (鼻). Aim for a clean gap between words when practicing phrases.
